# Ejerciciocibersegiridad
Ejercicio de Ciberseguridad en C++

Descripción

Este proyecto consiste en desarrollar un validador de contraseñas seguras utilizando el lenguaje de programación C++. El programa evalúa una contraseña ingresada por el usuario y determina su nivel de seguridad según cuatro reglas.

Objetivo

Aplicar los conceptos básicos de programación en C++ para validar contraseñas y clasificarlas según el cumplimiento de requisitos de seguridad.

Reglas de validación

El programa verifica las siguientes condiciones:

La contraseña tiene 8 caracteres o más.

Contiene al menos una letra mayúscula (A-Z).

Contiene al menos un número (0-9).

Contiene al menos un carácter especial de los siguientes: ! @ # $ % & *.

Clasificación de seguridad

DÉBIL: cumple entre 0 y 2 reglas.

MEDIA: cumple 3 reglas.

FUERTE: cumple las 4 reglas.

Tecnologías utilizadas

Lenguaje de programación C++.

GitHub para almacenar y entregar el código fuente.

Conceptos aplicados

Variables de tipo string.

Variables booleanas (bool).

Ciclo for.

Condicionales if, else if y else.

Comparación de caracteres.

Conteo de reglas cumplidas.

Archivo del proyecto
